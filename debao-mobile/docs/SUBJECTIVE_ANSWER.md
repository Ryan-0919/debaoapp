# 主观题作答与法条查询

更新时间：2026-08-31

## 已实现范围

- 从主观题选择页按科目和题目索引进入作答页。
- 支持题目切换、小问切换、文本输入、字数统计、上一题/下一问/下一题。
- 每个小问独立保存答案；手动保存同时写入本地草稿和 `QuestionService.saveDraft`。
- 提交前展示完成情况，确认后调用 `QuestionService.submit`。
- 作答页右上角提供法条检索入口。
- 进入法条检索前，将当前已填写答案写入本地草稿。
- 法条页接收当前科目并自动预筛选，展示“正在作答”上下文和“返回作答”按钮。
- 返回使用导航栈 `goBack()`，原作答页实例不销毁，当前题目、小问和答案保持不变；若页面被系统回收，已写入的本地草稿可恢复答案。

## 导航契约

```ts
LawSearch: {
  source?: 'subjective-answer';
  subject?: string;
} | undefined;
```

普通入口仍可不传参数。主观题入口传入：

```ts
navigation.navigate('LawSearch', {
  source: 'subjective-answer',
  subject: subjectName,
});
```

## 法条查询流程

1. 用户在主观题页填写一个或多个小问答案。
2. 点击右上角法条图标，客户端先保存所有非空答案的本地草稿。
3. 法条页打开并按当前科目预筛选。
4. 用户可搜索关键词、条文编号，打开全文或收藏法条。
5. 点击返回箭头或“返回作答”，回到原题继续输入。

## 真实业务边界

当前页面与本地交互已完成，但以下能力仍依赖后续生产数据和服务建设：

- 当前演示题目主要来自本地静态数据，需接入正式题库和题目版本。
- 法条真实模式调用现有检索 API；正式上线前仍需权威法条来源、全文索引、效力状态、版本和更新机制。
- 云端草稿接口已有契约，但跨设备恢复仍需服务端按用户、题目版本和小问合并草稿。
- 正式提交后仍需提交快照、重复提交保护、人工/AI 批改、结果通知和申诉闭环。
- 图片/PDF 附件上传尚未纳入当前作答页。
