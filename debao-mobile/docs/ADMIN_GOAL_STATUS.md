## 当前可验收入口

1. 启动服务端：`cd debao-server && npm.cmd run dev`（默认 `4000`）。
2. 启动后台：`cd debao-admin && pnpm.cmd dev`（默认 `8002`）。
3. 登录：本地 Compose 使用 `admin / local-compose-admin-2026`；生产环境必须使用密钥管理配置的管理员凭据。
4. 用户页：进入用户详情，执行限制、强制下线、权益调整。
5. 题库页：新建题目，发布，编辑已发布题目，查看版本历史。
6. 系统管理：绑定当前管理员 MFA；超级管理员可重置 MFA，重置会强制下线并审计。
7. 题库：维护试卷、导入题目预检并确认、创建/发布法条版本。
8. 课程：创建章节/课时、直播排期和批改任务领取/提交；商品页编辑价格会要求原因。
9. 运营：新建 Banner，管理公告草稿、定时发布、撤回和触达统计，配置消息模板和推送任务；未配置推送 Provider 时查看 blocked_provider 状态。
10. AI/分析：调整用户配额，查看风险/用量和分析概览；从 AI 用量或分析页创建导出任务并通过鉴权下载。
