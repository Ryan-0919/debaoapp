## 用例

| 范围 | 操作 | 预期 |
| --- | --- | --- |
| 听课 | 查看课程并打卡 | 显示站外听课文案，提交当前任务 ID，成功后显示已完成 |
| 解锁 | 未听课时打开卡片/题目 | 显示前置学习提示，无开始/完成入口，不误显示已完成，不请求锁定卡片内容 |
| 卡片 | 解锁后查看并确认背诵 | 加载指定卡片，提交当前卡片任务 |
| 题目 | 开始客观题 | 只传入分配的题目 ID 和学习任务 ID |
| 打卡失败 | 失败后重试 | 保持未完成状态；成功后再标记完成 |
| 交卷 | 作答并提交 | 保存答案、交卷成功后才完成学习任务并打开报告 |
| 交卷失败 | 失败后再次提交 | 不提前完成任务；重用幂等键重试 |
| 抽题 | 混有无关、草稿、停用、兄弟子考点题目 | 只选择已发布且在指定考点范围内的题，数量不足不跨考点补齐 |
| 空题池 | 无匹配题目 | 不生成无内容 ID 的题目任务，避免进入全库练习 |
| 发布 | 相关和无关考点混选 | 拒绝发布 |
| 考点层级 | 听课仅覆盖子考点却选择整个父考点 | 拒绝扩大范围；父考点覆盖子考点则允许 |
| 日程 | 列表靠前课程实际上排在后几天 | 不能作为前置听课内容 |
| 同日任务 | 随机 ID 顺序与课程/卡片/题目顺序相反 | 仍执行听课→卡片→练习；提前完成被拒绝，重复打卡不改变首次完成时间 |

## 运行

在 `debao-server` 目录运行：

```powershell
npm test
```

在 `debao-mobile` 目录运行：

```powershell
npm test -- --runTestsByPath __tests__/LearningTaskDetailScreen.test.tsx __tests__/LearningPracticeFlow.test.tsx __tests__/QuestionRemoteStates.test.tsx --silent
npm run typecheck
```

本次修复：锁定任务误显示已完成和提前请求卡片内容；同日任务按随机 ID 提前解锁；空题池生成无范围任务；混入无关考点、子考点扩大至父考点、未来课程被当作前置课程。

仍需人工验收：实际管理端创建发布→数据库重启后保留→手机获取计划→逐步完成→重新进入查看进度。卡片图片/HTML 的实际内容是否讲解所标注考点，需要运营审核，自动化只能验证配置与数据关联。
